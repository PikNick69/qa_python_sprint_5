Проект содержит набор автотестов для веб-приложения [Stellar Burgers](https://stellarburgers.education-services.ru/). Тесты покрывают основной функционал: регистрацию, вход, переходы между страницами, работу с личным кабинетом и разделами конструктора.
Технологии:
- Python 3.12
- pytest 8.3.1
- Selenium 4.27.0

Запуск тестов:
1. Скачайте ChromeDriver, соответствующий версии вашего браузера, и укажите путь к нему в системе или в коде фикстур.
2. Запустите все тесты из корневой папки: `pytest tests -v`
3. Для запуска конкретного файла: `pytest tests/test_login.py -v`

Структура проекта:
- `tests/` — директория с тестами.
- `locators.py` — файл с описанием локаторов.
- `conftest.py` — файл с фикстурами pytest.
- `data.py` — вспомогательные функции (генерация email, пароля).
